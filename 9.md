# Azure Virtual Machine Scale Sets (VMSS)

## 1. What is VMSS?
Azure Virtual Machine Scale Sets (VMSS) let you deploy and manage a set of identical, load-balanced VMs. They are designed for **scalability**, **high availability**, and **automatic scaling** based on demand.

VMSS is ideal for:
- Large-scale applications
- Microservices architectures
- Compute-intensive workloads
- Auto-scaling web servers or APIs

---

## 2. Key Features
- **Automatic Scaling**: Scale in/out based on CPU, memory, or custom metrics.
- **Load Balancing**: Integrates with Azure Load Balancer or Application Gateway.
- **High Availability**: Distributes VMs across fault domains and update domains.
- **Custom Images**: Use marketplace images or your own custom VM images.
- **Integration**: Works with Azure Monitor, Autoscale, and Azure DevOps.

---

## 3. VMSS Architecture
A VMSS consists of:
- **VM Instances**: Identical VMs created from a base image.
- **Scaling Policies**: Rules that define when to add/remove instances.
- **Load Balancer**: Distributes traffic across VM instances.
- **Resource Group**: Logical container for VMSS and related resources.
